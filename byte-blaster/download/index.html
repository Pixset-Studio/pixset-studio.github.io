ВОПРОСЫ ОБ УСТАНОВКЕINSTALL QUESTIONS

Перенесётся ли прогресс между версиями?Does progress carry between versions?

Прогресс из демо переходит в полную версию, если играть в том же браузере — они используют одно хранилище. Между браузером, Android и Windows прогресс не синхронизируется: сохранения хранятся на устройстве.

Demo progress carries into the full version when you play in the same browser — they share one storage. Progress does not sync between browser, Android and Windows: saves live on the device.

Нужен ли интернет?Do I need an internet connection?

Только для онлайн-кооператива. Всё остальное работает офлайн; Android- и Windows-версии не требуют сети вообще.

Only for online co-op. Everything else works offline; the Android and Windows builds need no connection at all.

Сколько весит игра?How big is it?

Около 250 МБ для настольной версии. Браузерная подгружается по частям — играть можно почти сразу.

Around 250 MB for the desktop build. The browser version streams in — you can start playing almost immediately.

Игра тормозит на слабом устройствеIt runs slowly on a weak device

Включите «Адаптивное качество» в настройках графики — игра сама снизит нагрузку при просадке кадров. Самый действенный ручной рычаг — «Разрешение рендера».

Turn on “Adaptive Quality” in the graphics settings — the game will lower the load by itself when frames drop. The strongest manual lever is “Render resolution”.
