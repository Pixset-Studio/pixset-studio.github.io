О ПРОЕКТЕABOUT

Byte Blaster — игра студии Pixset Studio. Один платформер, который одинаково работает в браузере, на Windows и на Android, переведён на 50 языков и умещается в 250 МБ.

Byte Blaster is a game by Pixset Studio. One platformer that runs the same in a browser, on Windows and on Android, translated into 50 languages and fitting in 250 MB.

Почему без движка и сборщика. Один и тот же набор файлов должен запускаться в Electron через file://, внутри Android-WebView и с обычного веб-сервера. Любой шаг сборки ломает хотя бы один из этих трёх маршрутов — поэтому игра осталась набором обычных скриптов. Why no engine and no bundler. The same set of files has to run in Electron over file://, inside an Android WebView and from a plain web server. Any build step breaks at least one of those three paths — so the game stayed a set of ordinary scripts.

ЧТО ВНУТРИ ИНТЕРЕСНОГОTHE INTERESTING PARTS

🗺

Карта, а не списокA map, not a list

Уровни расставлены по координатам и соединены дорогами, робот идёт по ним физически. На узком экране телефона кольцо уровней растягивается по ширине, а на ПК остаётся круглым.

Levels are placed by coordinates and joined by roads the robot physically walks. On a narrow phone screen the ring stretches to fit the width; on a PC it stays round.

🌍

50 языков без пропусков50 languages, no gaps

624 строки в каждом языке. Есть свой инструмент аудита: он ловит недостающие ключи, лишние, несовпадение подстановок и HTML-тегов — и отдельно отличает настоящий пропуск от законного заимствования.

624 strings per language. A custom audit tool catches missing keys, stale ones, mismatched placeholders and HTML tags — and separately tells a real gap from a legitimate loanword.

⚡

Работает на слабом железеRuns on weak hardware

Шесть уровней качества с автоопределением плюс адаптивный режим, который сам снижает нагрузку при просадке кадров. Время кадра доведено с 4 мс до 1.4 мс за счёт кэширования спрайтов и фоновых слоёв.

Six quality tiers with auto-detection, plus an adaptive mode that lowers the load by itself when frames drop. Frame time went from 4 ms to 1.4 ms through sprite and background-layer caching.

🤝

Честный кооперативCo-op that behaves

Сервер не знает правил игры — он только пересылает сообщения. Мир синхронизируется по стабильным идентификаторам с дельта-обновлениями и полным снимком раз в три секунды, чтобы опоздавший игрок сам починился.

The server knows no game rules — it only forwards messages. The world syncs by stable ids with delta updates plus a full snapshot every three seconds, so a late joiner heals itself.

КАК ЭТО ТЕСТИРУЕТСЯHOW IT IS TESTED

Почти всё, что может сломаться, ломается в браузере — поэтому проверки не про «функция вернула 2», а про настоящий запуск:

Almost everything that can break, breaks in a browser — so the checks are not about “the function returned 2” but about actually running the thing:

  • Игра запускается в настоящем окне, проходит уровни, гибнет, ставит паузу и дерётся с боссами — а сценарий смотрит на состояние.
  • The game boots in a real window, clears levels, dies, pauses and fights bosses while a script inspects the state.
  • Сетевой протокол проверяется на живых WebSocket-клиентах: комнаты, смена хоста, выход посреди уровня.
  • The network protocol is exercised with live WebSocket clients: rooms, host handover, leaving mid-level.
  • Интерфейс замеряется на профилях реальных экранов, включая телефон 20:9 и планшет — в CSS-пикселях, а не в физических.
  • The UI is measured against real screen profiles, including a 20:9 phone and a tablet — in CSS pixels, not physical ones.
  • Локализация и отсутствие захардкоженных строк проверяются автоматически перед каждой сборкой.
  • Localisation and the absence of hardcoded strings are checked automatically before every build.

НАШЛИ ОШИБКУ?FOUND A BUG?

Большинство исправлений в списке обновлений пришли от игроков. Чтобы сообщение было полезным, укажите:

Most of the fixes in the update list came from players. To make a report useful, include:

  • Что произошло и что вы ожидали вместо этого.
  • What happened and what you expected instead.
  • Где — какой уровень, режим и мир.
  • Where — which level, mode and world.
  • На чём — браузер, Android или Windows; модель телефона, если он.
  • On what — browser, Android or Windows; the phone model if it is one.
  • Повторяется ли — каждый раз или один раз.
  • Is it repeatable — every time, or just once.
