# Чтобы сайты находились в поиске

## Почему их не находило

Дело было не в текстах. Оба сайта живут на GitHub Pages, на них не ведёт ни одной
внешней ссылки, карты сайта не существовало, а в поисковые кабинеты их никто не
добавлял. Поисковику **неоткуда было узнать, что они есть** — он не обходит
интернет наугад, он идёт по ссылкам и по картам сайта.

## Что теперь сделано

| Что | Где лежит |
|---|---|
| `robots.txt` — один на весь домен | `Pixset Studio Site/robots.txt` |
| Карта сайта студии (21 адрес) | `Pixset Studio Site/sitemap.xml` |
| Карта сайта игры (7 адресов) | `Byte Blaster/Site/sitemap.xml` |
| Ключ IndexNow | `Pixset Studio Site/d9487c…a134.txt` |
| Генератор всего перечисленного | `Byte Blaster/Site/seo.js` |
| Отправка адресов в поисковики | `Byte Blaster/Site/indexnow.js` |

На каждой открытой странице теперь есть канонический адрес, описание, Open Graph
и Twitter-карточка, а на главных — разметка schema.org: студия описана как
организация, игра — как `VideoGame` с ценой, у вложенных страниц есть хлебные
крошки.

**robots.txt только один и только в репозитории студии.** Поисковик читает его
исключительно из корня домена; файл из репозитория игры лёг бы по адресу
`/byte-blaster/robots.txt`, куда никто не заглядывает. Поэтому ссылки на обе
карты сайта прописаны именно там.

## После добавления новых страниц

```bash
node seo.js
```

Скрипт сам обойдёт оба сайта, допишет недостающие теги (свой блок он каждый раз
заменяет целиком, так что дублей не будет), пересоберёт карты и `robots.txt`.
Страницы с `<meta name="robots" content="noindex">` он в карту не кладёт.

## Отправить адреса в поисковики

Только **после того, как сайт студии выложен** — иначе файл ключа ещё не
доступен по адресу и заявку отклонят.

```bash
node indexnow.js
```

Это Bing, Yandex, Seznam и Naver разом. Google протокол IndexNow не понимает.

## Что нужно сделать руками (я не могу — нужен вход в ваши аккаунты)

1. **Google Search Console** — https://search.google.com/search-console
   Добавить ресурс с префиксом `https://pixset-studio.github.io/`, подтвердить
   права HTML-файлом (скачать его и положить в корень сайта студии), затем
   «Файлы Sitemap» → добавить `sitemap.xml` и `byte-blaster/sitemap.xml`.
   Там же «Проверка URL» → «Запросить индексирование» для двух главных.

2. **Яндекс Вебмастер** — https://webmaster.yandex.ru
   То же самое: добавить сайт, подтвердить, указать карты сайта.

3. **Поставить ссылки на сайт там, где вас уже видно.** Это едва ли не важнее
   кабинетов: поисковик доверяет страницам, на которые ссылаются другие.
   - в описании канала YouTube и под роликами;
   - в шапке Telegram-канала;
   - в описании группы Roblox;
   - в поле **Website** у репозиториев на GitHub и в профиле `github.com/pixset`
     (профиль уже в индексе — ссылка оттуда сработает быстро);
   - в описании приложения в RuStore.

## Сколько ждать

Bing и Yandex после `indexnow.js` — обычно от нескольких часов до пары дней.
Google после Search Console — от нескольких дней до пары недель; без внешних
ссылок дольше. Раньше этого сайт в выдаче не появится, и это нормально.
