# Архивные версии и шлюз веб-версии

## Что где лежит

| Что | Где | Кто видит |
|---|---|---|
| Текущая веб-версия | `Site/game/` на GitHub Pages | все, но игру открывает только шлюз |
| Архивные сборки (`.html`) | приватный бакет Supabase `game-builds` | никто напрямую |
| Описания архивных версий | таблица `game_builds` | все (это витрина, файлов в ней нет) |
| Флаг «веб открыта» | `app_config.bb_web_open` | все на чтение |

**Файлы сборок на GitHub не выкладываются.** Для этого заведён `Site/.gitignore`.
Если положить `.html` в репозиторий, GitHub Pages раздаст его по прямому адресу
кому угодно, и любая проверка лицензии станет бессмысленной.

## Как закрыть или открыть веб-версию

Supabase → Table Editor → `app_config` → строка `bb_web_open`:

* `1` — играть в браузере можно (при наличии лицензии);
* `0` — нельзя. Игрока уводит на главную, даже если он пришёл прямо по адресу
  `/byte-blaster/game/`.

Пересобирать и выкладывать сайт не нужно — флаг читается при каждой загрузке.

## Как добавить архивную версию

1. Собрать HTML-версию игры: `npm run build:html` в `Game/`.
2. Supabase → Storage → бакет **game-builds** → загрузить файл, например
   `byte-blaster/1.0.2/index.html`. Бакет приватный, прямых ссылок из него нет.
3. Supabase → SQL Editor:

```sql
insert into public.game_builds (game_slug, version, label, storage_path, sort)
values ('byte-blaster', '1.0.2', 'Первая версия с секретным миром',
        'byte-blaster/1.0.2/index.html', 102);
```

Готово — версия появится на `/byte-blaster/archive/`.

## Как это защищено

Страница архива не знает адресов файлов. По нажатию «Играть» она просит
серверную функцию `build-access` выдать ссылку, и та:

1. проверяет токен игрока — без входа отказ `401`;
2. смотрит `my_entitlements` **его же токеном**, а не служебным, поэтому чужую
   лицензию подставить нельзя — отказ `403`;
3. сверяет, что запрошенная сборка принадлежит той игре, на которую есть
   лицензия, — иначе по одной лицензии можно было бы тянуть любую другую игру;
4. только после этого подписывает ссылку служебным ключом на 30 минут.

Ссылкой бесполезно делиться: она протухает. Права на бакет не выданы ни `anon`,
ни `authenticated` — подписать ссылку может только функция.

## Про честность шлюза веб-версии

Проверка в `assets/web-gate.js` выполняется в браузере, и её теоретически можно
обойти, отключив JavaScript. Но без JavaScript игра и не запустится — она вся на
нём. То есть шлюз ровно настолько прочен, насколько сама страница.

Настоящая граница проходит по файлам: то, чего нет в открытом доступе, нельзя
взять никаким обходом клиентской проверки. Поэтому архив живёт в приватном
бакете, а не рядом с сайтом.
