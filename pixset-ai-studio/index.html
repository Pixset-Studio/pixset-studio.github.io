ИНСТРУМЕНТЫ

Что умеет AI Studio

Все инструменты работают прямо в браузере через публичные API — без регистрации и установки.

🖼
PixGen
Генерация изображений по описанию. 7 форматов, 7 моделей (Flux, Anime, 3D и др.), улучшение промпта.
💬
PixGPT
Умный чат с AI. История диалога, быстрые промпты (код, стартап, перевод), Markdown-рендеринг.
🔗
PixQR
Генерация QR-кодов с кастомными цветами, размерами и уровнем коррекции ошибок.
⬆
PixUpscale
Апскейл изображений ×2/×4/×8 через Canvas API. Загрузка результата в один клик.
✂
PixCut
Удаление фона с фотографий. Автоматическое определение объекта, скачивание PNG.
📝
PixOCR
Распознавание текста с фотографий. Поддержка 50+ языков, копирование в буфер.
