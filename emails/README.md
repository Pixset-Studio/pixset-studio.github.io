# Письма аккаунта Pixset Studio

Здесь лежат шаблоны писем, которые Supabase отправляет игрокам: код
подтверждения при регистрации, вход по коду, смена пароля и смена почты.

| Файл | Куда вставлять в Supabase |
| --- | --- |
| `confirm-signup.html` | Authentication → Email Templates → **Confirm signup** |
| `magic-link.html` | то же → **Magic Link** |
| `reset-password.html` | то же → **Reset Password** |
| `change-email.html` | то же → **Change Email Address** |

Шаблоны написаны под вход **по коду**, а не по ссылке: в них подставляется
`{{ .Token }}` — те самые шесть цифр. Если когда-нибудь понадобится ссылка,
переменная называется `{{ .ConfirmationURL }}`.

Вёрстка нарочно старомодная — таблицы и стили прямо в атрибутах. Почтовые
клиенты не понимают ни flex, ни grid, ни подключаемые стили, а картинки многие
не загружают без разрешения, поэтому логотип набран текстом: письмо читается
даже с выключенными изображениями.

## Главное: от кого приходит письмо

Шаблон меняет только вид письма. **Отправителя он не меняет.**

Пока в проекте не настроен свой SMTP, Supabase шлёт письма со своего служебного
адреса вида `noreply@mail.app.supabase.io` — это и есть тот «непонятно кто» в
поле «От». Заодно у встроенной отправки стоит жёсткий лимит: **несколько писем
в час на весь проект**. Для живого магазина этого мало: два человека подряд
зарегистрировались — третий кода уже не дождётся.

Чинится это только подключением своего SMTP в
**Authentication → Emails → SMTP Settings**.

### Вариант А. Через почту студии на Gmail — выбран, делаем так

Отправитель станет `Pixset Studio <pixset.studio.offical@gmail.com>`.

1. В аккаунте Google включить двухэтапную проверку (без неё пароль приложения
   не выдаётся).
2. Создать **пароль приложения** (App Password) — Google выдаст 16 символов.
   Это отдельный пароль только для почты, основной пароль от аккаунта в
   Supabase вводить нельзя.
3. В Supabase → Authentication → Emails → SMTP Settings включить Enable Custom
   SMTP и заполнить:
   - Host: `smtp.gmail.com`
   - Port: `465`
   - Username: `pixset.studio.offical@gmail.com`
   - Password: пароль приложения из шага 2
   - Sender email: `pixset.studio.offical@gmail.com`
   - **Sender name: `Pixset Studio`**
4. Сохранить и проверить: зарегистрировать тестовый аккаунт и посмотреть, что
   написано в поле «От».

Ограничение Gmail — около 500 писем в сутки. Для нынешних объёмов с запасом.
Минус: адрес всё равно остаётся гмейловским, солиднее он не станет.

### Вариант Б. Со своим доменом — на будущее, когда появится домен

Отправитель станет, например, `Pixset Studio <noreply@pixset.studio>`.

1. Купить домен.
2. Завести аккаунт в почтовом сервисе (Resend, Brevo, Mailgun — у всех есть
   бесплатный тариф на несколько тысяч писем в месяц).
3. Добавить домен в сервисе и прописать у регистратора DNS-записи, которые он
   выдаст: **SPF и DKIM**. Без них письма уходят в спам.
4. В Supabase вписать SMTP-данные этого сервиса, Sender name — `Pixset Studio`.

Дороже на стоимость домена и полчаса возни с DNS, но именно так письма
перестают выглядеть самодельными, и доставляемость заметно лучше.

## Чего в письмах нет намеренно

- **Картинок.** Логотип текстом — письмо выглядит одинаково у всех и не зависит
  от того, разрешил ли клиент загрузку изображений.
- **Кнопок-ссылок.** Вход идёт по коду, а не по ссылке: ссылку в письме проще
  подделать, и почтовые сканеры иногда «прокликивают» её сами, гася одноразовый
  вход ещё до того, как игрок откроет письмо.
## Про два языка

Supabase шлёт один и тот же шаблон всем, а игра переведена на 50 языков —
поэтому письма двуязычные: сверху русский блок, под кодом английский. Код стоит
между ними: он одинаковый и в переводе не нуждается, а так его видно сразу,
на каком бы языке человек ни читал.

Если когда-нибудь понадобится третий язык — не добавляйте его в тот же шаблон,
письмо станет нечитаемым. Правильный путь: отправлять письма своей edge-функцией
и выбирать язык по полю `locale` в профиле игрока (оно уже есть, его пишет
`update_locale`).
